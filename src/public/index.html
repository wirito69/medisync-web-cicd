Giro de Negocio: MediSync SaaS

1. ¿Qué es MediSync?

Es una solución de software como servicio (SaaS) orientada a centros de salud ambulatorios, policlínicos y médicos independientes para modernizar el proceso de reserva, confirmación y triaje inicial de consultas médicas.

2. Problema del Negocio

Hasta un 28% de ausentismo de pacientes en clínicas tradicionales por falta de confirmación oportuna y saturación de líneas telefónicas, lo que causa pérdidas financieras en horas de especialistas médicos no aprovechadas.

3. Propuesta de Valor

  • Autogestión de citas para pacientes 24/7.
  • Validación automática de horarios para evitar solapamiento entre médicos y pacientes.
  • Monitoreo de métricas clínicas en tiempo real para la administración.

4. Modelo de Monetización

Suscripción mensual por médico activo (Freemium hasta 2 especialistas, Plan Pro con recordatorios WhatsApp y reportes avanzados).

Arquitectura del Pipeline CI/CD

1
Etapa de Calidad de Código (Linting)

Ejecuta ESLint para asegurar apego a estándares de codificación, detección de variables no usadas y estilo uniforme.

2
Etapa de Pruebas Unitarias & Integración (Jest)

Valida reglas de negocio: fechas futuras, especialidades autorizadas, no solapamiento de médicos. Si un test falla, el pipeline aborta.

3
Etapa de Despliegue Continuo (CD)

Solo si la rama es main y los tests están en verde, se empaquetan los artefactos y se publica la versión estable.
